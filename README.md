# 天台马后炮 Rooftop Hindsight

股票历史拐点共性挖掘与点位回测工具（天台系列独立模块）。

给定一只股票、回测周期（默认 2 年，可选 1 / 3 / 5 年）和波段涨幅阈值（默认 10%，可改），通过**「代码提取历史高低点客观账本 → AI 自由归纳共性特征 → 代码全历史逐日回测验算真实概率 → 对照当前 K 线给出参考点位」**的闭环，回答三个问题：

1. **高胜率买点**：过去每次从阶段低点走出 ≥ 目标涨幅的波段，起点有什么技术指标或形态共性？历史上出现该特征时真实胜率是多少？
2. **有效支撑与压力**：这只股票真正认哪条均线、哪个指标或形态组合？碰到时守住率、假跌破（N 天内收回）比例是多少？
3. **破位与走坏特征**：出现什么信号（如连续 2 天跌破某均线、冲不破 EMA5 且顶背离）时，历史上大概率继续下跌创新低？

本工具仅负责**历史规律挖掘与入场/支撑/压力点位分析**，不负责仓位计算与持仓止损止盈执行（持仓执行由 [trade-discipline](https://github.com/gunzero5158/trade-discipline) 负责）。
